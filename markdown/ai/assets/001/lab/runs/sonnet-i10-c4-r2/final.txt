That's not just under-specified, it's a direct contradiction with the README's "every ingest path" wording and with the existing JSON-path test in the same file.

- violate the documented "must survive every ingest path exactly" guarantee,
- make `parse_csv` and `parse_line` disagree on the same id, breaking `merge_batches`' dedup-by-id contract for any id above 2^53 arriving via both paths.

I'm not going to make that change.
