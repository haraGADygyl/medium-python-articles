The README says the heading should read `loop` in that case, so I changed `_heading` to return `"loop"` and set its return type to `str`. I didn't loosen `Summary.heading` to `str | None`, because that would only have hidden the bug.

No existing test covers a loop track, so the `loop` output is only checked by mypy and the README's description. A test for it would be worth adding.
