**The conflict**
- `README.md` says buoys re-send a batch when an upload isn't acknowledged, so the same observation can arrive twice, and "`ingest.merge_batches` keeps the first copy of each `observation_id`." The function's docstring says the same, and the code does exactly that.

The test also looks bolted on: it sits directly after the previous test with no blank line between them, unlike every other test in the file.

**Options**
